<h1 align="center">回序</h1>

<p align="center">把生活，慢慢过回来。</p>

回序是一套无需账号、本地优先的渐进式生活挑战工具。它面向生活状态混乱、作息失序、注意力分散，或者只是想重新找回日常节律的人。

回序不要求用户时刻进步，也不把生活变成一场自我优化竞赛。它希望帮助人从起床、吃饭、喝水、活动身体、整理空间和记录生活这些普通的小事开始，重新建立可以持续的生活支点。

> 身体状态优先于效率，基础生活优先于额外成长，稳定重复优先于短期爆发。

## 当前状态

项目目前处于公开测试准备阶段。核心挑战流程、数据保存、历史归档、备份恢复和移动端界面已经可以完整使用；线上体验地址将在正式部署后补充。

## 主要功能

- 四条挑战路线：7日清场、21日稳定、50日挑战和自定义挑战
- 按设备本地自然日自动推进，不需要手动进入下一天
- 今日打卡、达标判断、挑战进度、每日记录与历史归档
- 挑战暂停、恢复和提前结束，已经发生的记录不会归零
- 自定义任务、个人目标和生活节律
- “给生活加一点”生活盲盒，不计入挑战和达标
- 本地提醒与安装到手机主屏幕或电脑桌面
- 完整备份、恢复和 Markdown 可阅读记录导出
- 无需注册登录，挑战数据默认只保存在当前设备

## 四条挑战路线

### 7日清场

从眼前最真实的生活阻力开始。每天完成一个清场项目，并保留身体和注意力两个小锚点。7天内完成至少5个清场挑战，并在第7天留下回序卡，即完成本轮挑战。

### 21日稳定

通过固定起床、主动活动和收回注意力三项固定挑战建立生活节律，并搭配一项附加挑战。前三项全部完成记为稳定日；21天内获得至少15个稳定日，并完成至少15次附加挑战，即完成本轮挑战。

### 50日挑战

围绕稳定起床、晨间仪式、主动活动、好好吃饭、每日记录与反思五项基础挑战进行长期实践。每天完成4项记为达标日，5项全部完成记为全部完成日；50天内累计至少40个达标日，即完成本轮挑战。五项可选挑战只用于探索，不影响当天判定。

### 自定义挑战

用户可以创建3—50天的挑战，从固定路线或系统题库中选择项目，也可以新增自己的任务。每项任务支持每天、隔一天和每周指定日期三种生活节律；系统会根据当天实际出现的任务和用户设置的容错数量判断完成日、达标日或未达标日。

## 给生活加一点

生活不只有需要完成的事情，也值得被感受、体验、玩耍、连接和创造。

“给生活加一点”是一组不影响打卡、不影响达标、也不要求完成的生活盲盒。用户可以随机抽取一件小事、换一个结果、收藏，或者记下自己想试试的内容。它不是新的任务系统。

## 数据与隐私

- 回序不设置账号系统。
- 挑战状态主要保存在浏览器 IndexedDB，并保留 localStorage 兼容层。
- 开发者无法查看用户写下的每日记录、自定义目标或挑战内容。
- 更换设备或清理浏览器数据前，需要由用户主动导出完整备份。
- 匿名使用统计由 Umami Cloud 提供，并且只会在用户明确允许后加载统计脚本、发送预先限定的功能事件。
- 匿名统计不会发送文字记录、任务内容、时间设置、备份文件、持久用户ID或设备指纹，用户可以随时在“我的”页面关闭。

完整说明请参阅 [PRIVACY.md](./PRIVACY.md)。

## 提醒能力说明

当前提醒采用浏览器本地通知：网页正在运行时可以准点提醒，从后台恢复时可以补发短时间内错过的提醒。完全退出浏览器后，纯前端网页无法自行唤醒；项目目前没有接入后台 Web Push 服务。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

## 项目结构

- `app/HuixuApp.tsx`：产品状态、挑战生命周期与主要交互
- `app/challengeData.ts`：三条固定路线、任务内容、规则与每日文案
- `app/customChallenge.ts`：自定义挑战题库、生活节律与每日快照
- `app/challengeClock.ts`：本地日期、跨天推进、暂停与结束边界
- `app/lifeSparkData.ts`：生活盲盒分类、题库与随机逻辑
- `app/huixu.module.css`：视觉系统与移动端适配
- `public/sw.js`：Service Worker 与离线基础能力
- `public/manifest.webmanifest`：PWA 安装配置
- `worker/index.ts`：Cloudflare Worker 入口
